# Leakage-prone-V-S-leakage-resistant-study-for-concrete-compressive-strength-pediction
This repository explores data leakage in ML models for concrete compressive strength prediction, contrasting leakage-prone and leakage-resistant workflows. Implemented in Python with reproducible, generalization-focused evaluation. 

#Data Set
Data set is taken from the UCI Open source machine learning repository.
